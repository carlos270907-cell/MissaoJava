# Missão Java - Códigos base dos exercícios 1 a 7

Cada pasta corresponde a um exercício do PDF. Os arquivos não contêm soluções.

- Exercícios 1 a 5: há trechos TODO para o aluno implementar. Eles **não compilam inicialmente**, por projeto, nos exercícios 2 a 5, pois faltam os métodos pedidos.
- Exercícios 6 e 7: o código original já funciona; a tarefa é refatorá-lo. O exercício 7 também exige implementar funcionalidades novas.

## Executar (OpenJDK 21)
Entre na pasta de um exercício e execute:

    javac Main.java
    java Main

Nos exercícios 6 e 7, substitua Main por SistemaLoja e SistemaVendas, respectivamente.

Arquivos em UTF-8. Compile cada exercício em sua própria pasta.
